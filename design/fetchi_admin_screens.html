Fetchi.ai — Admin Screens Reference

UI reference for the admin operations platform at /admin. This file shows exact layouts, components, and data patterns for Claude Code to follow. The admin uses the same design tokens (fonts, colors) as the main app but with a distinct tool-like layout — no ツ branding, dark sidebar, utilitarian aesthetic.

Companion files: fetchi_core_screens.html (main app), fetchi_settings_screens.html (settings), fetchi_map_view.html (map tab)

Route: GET /admin/workspaces. Paginated, sortable, filterable list of all workspaces. Filter pills: All, Active, Trial, At risk, Churned. Plan dropdown filter. Search by name/email/ID. Screen 16: Data export — /admin/data
Route: POST /admin/data/[workspace_id]/export. Five export types: Workspace data, Revenue/billing, Agent performance, Signal/opportunity data (anonymized for marketplace), Audit log. All exports logged in the events table. PII stripped from signal exports. GDPR delete endpoint: POST /admin/data/[workspace_id]/delete with confirmation param.
fetchiAdmin console
