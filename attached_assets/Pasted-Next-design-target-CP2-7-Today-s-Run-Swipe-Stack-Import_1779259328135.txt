Next design target: CP2.7 — Today’s Run / Swipe Stack.

Important product rule:
The swipe-card concept is NOT part of My Leads. My Leads is the archive/pipeline list over opportunities. Today’s Run is the active daily review session where swipe cards live.

Goal:
Design and implement the Today page as the destination from the “Today’s Run · 3 leads queued” CTA on My Leads.

Use the existing Cash App × Claude × Fetchi design language:
- parchment background
- near-black primary surfaces
- brand green accents
- large calm typography
- rounded cards
- mobile bottom nav unchanged
- desktop dark sidebar unchanged

Today’s Run should feel like:
“Here are the best leads Fetchi found for you today. Review one at a time. Add, pass, or open evidence.”

Mobile layout:
- Existing top mobile header stays unchanged.
- Page title: Today’s Run
- Subtitle: “3 leads queued for review”
- One large swipe-style LeadCard/run variant centered on screen.
- Card shows:
  - status pill
  - signal token
  - score
  - business name
  - location
  - why-now summary
  - best contact preview if present
  - evidence count
- Bottom actions under card:
  - Pass
  - Open evidence
  - Add to My Leads
- Add to My Leads sets status to saved.
- Pass sets status to skipped.
- Open evidence links to /app/leads/[id].
- No actual drag/swipe gesture required yet unless already simple; buttons are enough for CP2.7.
- Show progress: “1 of 3”
- After action, advance to next queued lead.
- Empty/completed state: “Today’s Run complete” with CTA back to My Leads.

Desktop layout:
- Same content, centered max-width.
- One focused run card, not a grid.
- Optional right-side mini queue preview is okay, but do not make it a CRM board.
- The page should feel calmer than My Leads and more decisive.

Data rules:
- Query opportunities where status IN ('new', 'saved') for the workspace.
- Rank by score descending.
- Limit to today’s queued count or top 3 for now.
- If workspace has no opportunities, use dev-only visual fallback gated by NODE_ENV !== 'production'. No DB writes. No seed edits.
- Do not invent new schema fields.
- Do not create a new status for Today’s Run. Today’s Run is a session view, not a database state.

- optional new components/app/TodaysRunView.tsx
