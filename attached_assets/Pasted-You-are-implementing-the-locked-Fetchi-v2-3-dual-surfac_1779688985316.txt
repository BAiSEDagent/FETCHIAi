============================================================
CORE BRAND PRINCIPLE
============================================================

Fetchi is now a dual-surface brand system:

1. DARK / OPERATOR PRODUCT
Default theme for authenticated product workflows.

2. CREAM / LIGHT / SMB
Default theme for public marketing, onboarding, pricing, SEO pages, and future opt-in Light Mode.

The brand tokens stay shared across both themes:
- coral
- evidence blue
- success green
- warning amber
- danger red
- typography
- lead-card rules
- wordmark
- coral usage discipline

The chrome flips by context:
- Dark for the operator cockpit.
- Cream/light for everything public-facing or onboarding-facing.

============================================================
CORAL USAGE DISCIPLINE
============================================================

Coral is rare.

Coral is NOT the general Fetchi decoration color.
Coral is the valuable-action color.

Coral may appear only in these contexts:

1. Hot/urgent lead card surface
2. Primary CTA
3. Score on a hot card
4. Active high-value action
5. Trial gate / upgrade / monetization moment
6. One italic emotional kicker per major marketing section

Coral must NOT appear in:

- product section labels
- generic chips
- decorative dots
- icon backgrounds
- repeated headline pills
- evidence labels
- secondary buttons
- neutral admin tables
- normal body text
- all active nav states
- repeated product chrome
- generic badges
- every status pill

Important:
The previous v2.0 design used coral in roughly 22 distinct places.
The v2.1 discipline reduces this to about 5 high-value surfaces.
Preserve that discipline.
