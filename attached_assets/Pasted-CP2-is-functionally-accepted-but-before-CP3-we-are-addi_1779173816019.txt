Do not start CP3.

Goal:
Upgrade the Fetchi UI direction across the customer app before more screens are built.

Design target:
A mix of Cash App UX/UI and Claude.ai UX/UI, adapted to Fetchi’s brand.
Do not clone either product. Use them as inspiration:
- Cash App: simple, bold, mobile-first, clear CTAs, big touch targets, clean flows, low friction
- Claude.ai: calm, warm, spacious, conversational, thoughtful copy, soft neutral surfaces
- Fetchi: ツ avatar, brand green #58937E, dark #2D2B2A, parchment #EBE6D9, Outfit headings, DM Sans body

First create or update a design-system document:
- DESIGN_SYSTEM_V2.md
Include:
1. Visual principles
2. Color usage rules
3. Typography scale
4. Spacing/radius rules
5. Button styles
6. Card styles
7. Chat/message styles
8. Lead card styles
9. Onboarding patterns
10. Mobile bottom-nav rules
11. Empty/loading/error states
12. What to avoid

Then apply the design system to CP2 customer screens only:
- /

- /sign-up

- /blocked
- /app/onboarding
- /app/chat
- /app/leads

- /app/settings/profile
- customer shell/sidebar/mobile nav

Specific UX requirements:
- Onboarding should feel like Cash App simplicity: one decision per step, large tappable options, minimal copy, clear progress
- Chat should feel closer to Claude: calm conversational layout, readable assistant responses, strong composer, lead cards embedded naturally
- Lead cards should feel like clean Cash App transaction cards mixed with evidence-first sales intelligence
- Settings should be grouped into simple calm cards, not dense SaaS forms
- Mobile-first at 375px
- Minimum 44px touch targets
- Do not use generic purple Clerk styling if avoidable; theme Clerk to Fetchi
- Do not overuse borders; prefer soft surfaces, spacing, and hierarchy
- Preserve all existing CP2 functionality and data writes

Data/architecture rules:
- Do not modify db/schema.ts, db/index.ts, db/seed.ts, or drizzle.config.ts
- Preserve Clerk auth, webhook, workspace provisioning
- Preserve workspace_id scoping
- Preserve opportunities as the backing data for “My Leads”
- No live LLM calls
- No live search calls

After changes:
- Run npm run type-check
- Run npm run build
- Verify customer routes still compile
- Return CP2.2 report with:
  - DESIGN_SYSTEM_V2.md summary
  - files changed
